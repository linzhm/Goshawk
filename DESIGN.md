# Goshawk visual identity

Goshawk / 苍鹰 is an independently branded derivative of Sparrow. This change
is limited to product identity and its native desktop surfaces, not a rewrite
of the wallet's information architecture.

The authoritative assets and usage rules are in `docs/brand/README.md`.
The mark is an authored vector goshawk profile, with a pronounced eyebrow and
hooked beak. Palette: ink `#192A35`, slate `#31566A`, paper `#F4F2ED`, amber
`#D49A44`. Wordmark: outlined Space Grotesk 600; app text: existing native fonts.

Native desktop surfaces operate existing wallet tasks. Preserve information
density, keyboard operation, financial status colours and transaction detail.
Express the brand through application icons, restrained focus/selection colours,
empty state, introduction and About. Preserve light/dark theme legibility.

Always distinguish planned BSV services from the currently inherited Bitcoin
backend. Keep Sparrow attribution, license access and its explicitly labelled
donation link visible in About. Product-specific files belong in
`branding/goshawk/`; upstream source files receive only narrow integration hooks.
